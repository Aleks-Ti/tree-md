# Bool

`bool` — подкласс `int`: `True == 1`, `False == 0`.

```python
isinstance(True, int)   # True
True + True             # 2
```

## Что считается ложным (falsy)

| Значение | Тип |
| --- | --- |
| `None` | см. [[None]] |
| `False`, `0`, `0.0`, `0j` | числа |
| `""`, `[]`, `()`, `{}`, `set()`, `range(0)` | пустые коллекции |
| объект с `__bool__() -> False` или `__len__() == 0` | пользовательские классы |

Всё остальное — истина.

## Порядок проверки в `bool(x)`

1. Если определён `__bool__` — вызывается он.
2. Иначе, если определён `__len__` — истина, когда длина ≠ 0.
3. Иначе — `True`.

## Подводные камни

- `if x:` и `if x is not None:` — не одно и то же: `0` и `""` тоже falsy.
- `and`/`or` возвращают **операнд**, а не `bool`: `0 or "a"` → `"a"`.
- Сравнивать с `None`/`True` — через `is`, не `==`.
