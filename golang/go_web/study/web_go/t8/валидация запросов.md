## Идея

Данные клиента нельзя считать корректными. Библиотека `github.com/go-playground/validator/v10` проверяет структуру по правилам из тега `validate:"..."`. Сначала `BodyParser`, затем `validate.Struct(req)`; при ошибке — `422 Unprocessable Entity`.

## Базовая валидация (theory/0)

```go
type CreatePostRequest struct {
    UserID int64  `json:"user_id" validate:"required,min=0"`
    Text   string `json:"text" validate:"required,max=140"`
}

validate := validator.New()

webApp.Post("/posts", func(ctx *fiber.Ctx) error {
    var req CreatePostRequest
    if err := ctx.BodyParser(&req); err != nil {
        return fmt.Errorf("body parser: %w", err)
    }
    err := validate.Struct(req)
    if err != nil {
        return ctx.Status(fiber.StatusUnprocessableEntity).SendString(err.Error())
    }
    return ctx.SendStatus(fiber.StatusOK)
})
```

## Своё правило (theory/1)

```go
Text string `json:"text" validate:"required,max=140,allowable_text"`

vErr := validate.RegisterValidation("allowable_text", func(fl validator.FieldLevel) bool {
    text := fl.Field().String()
    for _, word := range forbiddenWords {
        if strings.Contains(strings.ToLower(text), word) {
            return false
        }
    }
    return true
})
```

## ДЗ: пользователи (dz)

```go
CreateUserRequest struct {
    ID      int64  `json:"id" validate:"required,min=1"`
    Email   string `json:"email" validate:"required,email"`
    Age     int    `json:"age" validate:"required,min=18,max=130"`
    Country string `json:"country" validate:"required,allowable_country"`
}
```

Кастомное правило `allowable_country` пропускает только `USA`, `Germany`, `France`. Роут `POST /users`: ошибка парсинга — 400, ошибка валидации — 422, успех — 200.

## Запуск и проверка

```bash
go run .
curl -X POST http://localhost:8080/users -H "Content-Type: application/json" \
  -d '{"id":1,"email":"a@b.com","age":30,"country":"USA"}'        # 200
curl -i -X POST http://localhost:8080/users -H "Content-Type: application/json" \
  -d '{"id":1,"email":"bad","age":10,"country":"Mars"}'           # 422 + текст ошибок
curl -i -X POST http://localhost:8080/posts -H "Content-Type: application/json" \
  -d '{"user_id":1,"text":"hello"}'                               # theory (порт 8080)
```

## Подводные камни

- `required` для числа считает ноль «пустым»: `user_id: 0` не пройдёт `required`, хотя `min=0` допускает ноль.
- `validator.New()` создают один раз (он кэширует структуру), а не на каждый запрос.
- Ошибку `RegisterValidation` нужно проверять (в theory/1 это сделано, в dz возвращаемое значение игнорируется).
- `err.Error()` отдаётся клиенту как есть: это внутренние имена полей Go, для API лучше формировать свой ответ.
- Валидатор проверяет значения, а не формат JSON: сломанный JSON отсекает `BodyParser`.
