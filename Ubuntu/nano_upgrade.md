# Улучшение для Nano

создать файл в директории `~/.nanorc`

добавить конфиг:

```bash
set mouse  # добавит интерактив мышкой
set autoindent
set linenumbers  # нумерует строки
set tabsize 4  # таб по умолчанию будет 4 пробела ставить
```
